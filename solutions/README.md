Annotated reference answers for the stubs in [`problems/`](../problems/).
**Read them after you've actually tried**, not before.

The comments explain *why* each approach works and what the alternative was,
not just what the code does. Where there's a faster variant (bucket sort
instead of a heap, counting instead of sorting), it's noted inline.
