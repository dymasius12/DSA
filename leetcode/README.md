# LeetCode solutions

Real LeetCode problems I've solved, one file each, grouped by module. The code
in each file is **exactly what I submitted**, planning comments included, with
review notes and tests added around it.

## Relearning from these files

Each file is laid out so you can **re-solve it without spoilers**:

1. Read only the header docstring: the problem, the pattern, the key insight.
2. Stop there. Solve it on LeetCode, or in a blank file.
3. Then scroll down and compare: the submitted solution, the review notes (what
   could be better and why), and any alternative versions.
4. Run the file to see every claim in the notes checked:

```bash
python3 leetcode/06_linked_list/0141_linked_list_cycle.py   # one file
./check leetcode                                           # all of them
```

If the pattern name alone isn't enough to get you started, that's the topic to
revisit in [`../cheatsheets/_patterns.md`](../cheatsheets/_patterns.md).
