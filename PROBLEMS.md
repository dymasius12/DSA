# Problems

The **Blind 75** — the standard curated list — mapped onto this repo's modules.
75 problems: 20 Easy, 48 Medium, 7 Hard.

This is the *what*. [`cheatsheets/_patterns.md`](cheatsheets/_patterns.md) is
the *how*. Tick things off here as they get solved.

**Legend:** 🟢 Easy · 🟡 Medium · 🔴 Hard · ✅ = a stub + tests exist in this repo

> The wider **NeetCode 150** adds 75 more problems on top of these, filling the
> difficulty gaps between them. Same 18 categories, so the same map applies —
> Blind 75 first, then widen.
